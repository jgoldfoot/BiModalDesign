AOM Integration Example

This example demonstrates how to build a Custom Element (Web Component) using the ElementInternals API to natively expose semantics to the Accessibility Object Model (AOM).

By using attachInternals(), this toggle button directly sets its role, ariaChecked state, and ariaLabel without relying on custom data-agent-* attributes or cluttering the light DOM. This makes the component fully accessible to humans and robustly discoverable by Level 2 (Browser Automation) and Level 3 (Vision & Computer-Use) agents.
