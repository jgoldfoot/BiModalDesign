Multi-Step Form Optimization for Open-Source Agents

This example demonstrates how to optimize complex forms for DOM-first open-source browser agents like Browser-Use and Skyvern. Rather than relying on custom data-agent-* attributes, this form uses strict standard web attributes (Layer 2) to convey semantic boundaries, state, and requirements.

  • Uses <fieldset> and <legend> for semantic grouping.
  • Explicit for / id pairing on labels and inputs.
  • Utilizes standard HTML5 constraints (required) mapped to AOM (aria-required).
  • Provides accessible descriptions via aria-describedby for help text.
