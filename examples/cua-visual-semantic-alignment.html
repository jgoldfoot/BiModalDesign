Visual-Semantic Alignment for Multimodal Agents

Multimodal Computer-Using Agents (like Claude Mythos) use both vision (screenshots) and the accessibility tree (AOM) to navigate. When the visible text does not match the accessible name, these agents often fail to correlate the visual bounding box with the underlying interactive element.

This follows WCAG 2.5.3: Label in Name. The accessible name must contain the visible text.

Anti-Pattern (Mismatched)

Agent Failure Mode: The vision agent sees the text "Buy Now". It queries the accessibility tree for a button named "Buy Now". It cannot find one, because the developer overrode the accessible name with an aria-label that does not contain the visible text.

Recommended Pattern (Aligned)

Agent Success Mode: The vision agent sees "Buy Now" and finds a matching element in the accessibility tree. The accessible name is exactly the visible text.

Anti-Pattern (Icon with Mismatched Aria-Label)

Agent Failure Mode: The user sees the text "Add to Favorites" next to an icon. The button has an aria-label="Save Item". The vision agent is confused by the mismatch between the visible text and the accessible name.

Recommended Pattern (Icon with Aligned Text)

Agent Success Mode: The accessible name contains the visible text. The vision model and the accessibility tree are perfectly aligned.
